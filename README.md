# Plan Your Care

A healthcare discovery app for finding reproductive healthcare information, nearby clinics, and state-level resources.

![Plan Your Care interface](docs/images/plan-your-care.png)

## About

Plan Your Care was built for WingHacks to make reproductive healthcare information easier to understand and navigate. The app combines credible resources, an interactive map, a clinic locator, and a guided chat experience.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Express
- MongoDB
- Google Maps APIs
- EmailJS

## Features

- State-level reproductive healthcare information.
- Interactive map UI.
- Local clinic locator.
- Resource pages for care options and policy context.
- Chat-style guidance flow.
- Backend API for application data.

## Recognition

Plan Your Care received Best Overall and Best Use of MongoDB at WingHacks.

## My Role

## Running Locally

Frontend:

```bash
git clone https://github.com/mattcattb/Winghacks.git
cd Winghacks/frontend
npm install
npm run dev
```

Backend:

```bash
cd ../backend
npm install
npm run dev
```

Create local environment files for API keys, database URLs, and email configuration before running the full app.
